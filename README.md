# Python OpenCV Color Detector_YELLOW

A Python script using OpenCV and NumPy to detect yellow objects.

## Features
* Captures video from the webcam.
* Converts video frames to HSV color space.
* Uses a color mask to isolate yellow objects.

## Tech Stack
* Language: Python
* Libraries: OpenCV, NumPy
